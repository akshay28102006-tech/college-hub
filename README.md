# 🎓 College Hub

College Hub is a student resource sharing platform where students can upload and access notes, previous year questions (PYQs), important questions, assignments, and study materials.

## 🚀 Features

### Authentication

* User Registration
* User Login
* User Logout
* Theme Switching (Light/Dark)

### User Profiles

* Full Name
* Branch
* Semester
* Bio

### Upcoming Features

* Resource Upload
* Resource Library
* Search & Filter
* Download Counter
* Resource Ratings
* Contributor Badges

## 🛠 Tech Stack

### Backend

* Django
* PostgreSQL

### Frontend

* Django Templates
* Tailwind CSS
* DaisyUI

### Version Control

* Git
* GitHub
